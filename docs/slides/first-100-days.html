Read

Use the signals that already have a source.

CSAT

Customer satisfaction with one interaction, purchase, or product. A short-term score.

NPS

Net Promoter Score. How likely a customer is to recommend Vention. A longer-term loyalty score.

Application performance

Response time, error rate, and resource use. The worst endpoints and the worst SQL queries.

Real user monitoring

What the browser sessions already show. Datadog, Splunk, Prometheus, or the tool already on the wall.

A metric belongs on the board when it has a source

  • Which areas are untested, and where are the weak spots?
  • Which tools and dashboards already show quality?
  • What makes continuous integration and delivery hard for developers?

Release today

  • Delivery's current release flow.
  • What defines go or no-go on cloud, on the two-week cycle.

This is the picture the baseline sits on

Baseline, then gates

A small set of numbers. Thresholds after that.

Cloud

Continuous-integration pass rate. Flake rate. Web vitals. Post-deploy smoke.

Edge

EtherCAT link-loss during soak. Memory growth. Update success and resume rate. Pass rate across firmware versions.

Both

Escaped defects. A number becomes a gate only after the baseline exists, on the dashboard the teams already open.

Cloud can take a gate from the two-week pipeline. Edge waits on the lab.
